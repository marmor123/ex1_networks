# Bug Fixes for TCP Throughput Benchmark

> **For agentic workers:** Each step uses checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix 8 confirmed bugs found during code review — SIGPIPE, MSG_COUNTS duplication, warmup timing skew, division by zero, bounds check, stale errno, unchecked setsockopt, and size_t overflow.

**Architecture:** Fixes touch all 4 source files. The largest change moves warmup from per-size to one-time at connection start. MSG_COUNTS moves to common.cpp with extern in common.h. All other fixes are single-line.

**Tech Stack:** C++17, POSIX sockets

---

### Task 1: Fix SIGPIPE — add MSG_NOSIGNAL to send()

**Files:**
- Modify: `common.cpp:43`

Change `send(fd, ptr + total, n - total, 0)` to `send(fd, ptr + total, n - total, MSG_NOSIGNAL)`.

### Task 2: Move MSG_COUNTS to single source of truth

**Files:**
- Modify: `common.h` — add `extern const size_t MSG_COUNTS[];`
- Modify: `common.cpp` — add MSG_COUNTS definition (moved from server.cpp)
- Modify: `server.cpp` — remove MSG_COUNTS, use extern from common.h
- Modify: `client.cpp` — remove MSG_COUNTS, use extern from common.h


Add in common.cpp (after includes):
```cpp
const size_t MSG_COUNTS[] = { ... };  // moved from server.cpp
```

Remove MSG_COUNTS definitions from server.cpp and client.cpp.

### Task 3: Fix warmup timing skew — one-time warmup

**Files:**
- Modify: `server.cpp` — receive one-time warmup, then receive only MSG_COUNTS[i] per size
- Modify: `client.cpp` — send one-time warmup, then send only MSG_COUNTS[i] per size
- Modify: `common.h` — add WARMUP_BYTES constant (e.g., 8MB total: 8 messages of 1MB)

The client sends a fixed number of large messages at connection start. Server receives and discards. Then per-size batches use only MSG_COUNTS[i] messages (no warmup per size), so elapsed time measures only timed data.
